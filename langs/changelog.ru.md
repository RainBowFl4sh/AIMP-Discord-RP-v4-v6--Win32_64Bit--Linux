# Список изменений

## 1.5.3

### Новое
- **AIMP 4 и AIMP 3**: плагин теперь поддерживает и AIMP 4 - полностью, со страницей настроек, установкой
  `.aimppack` и автоматическими обновлениями, - и с небольшими ограничениями AIMP 3: статус в Discord работает, но в
  AIMP 3 нет страниц настроек для плагинов и он не умеет устанавливать пакеты, поэтому плагин устанавливается вручную,
  а настраивается в `DiscordRPC.ini`
- **x0.at** как сервис загрузки локальных обложек (без аккаунта) - новый вариант по умолчанию. catbox.moe сейчас
  ничего не отвечает на загрузки без аккаунта, а файлы, загруженные с аккаунтом, отдаются пустыми (0 байт)
- Каждая загруженная обложка проверяется до того, как Discord получит ссылку. Если сервис не сработал или ничего не
  отдаёт, его заменяет следующий (x0.at / catbox.moe), а неработающий сервис пропускается 30 минут
- Загруженные обложки старше 3 дней проверяются один раз за сеанс AIMP; если сервис удалил файл, обложка
  загружается / ищется заново

- **Обложки в Discord проверяются**: Discord загружает обложки через свой медиа-прокси и иногда показывает «?»
  вместо картинки (и запоминает это для ссылки). Через несколько секунд после отправки плагин проверяет копию
  обложки в Discord. Если Discord не может её загрузить, та же картинка отправляется заново под новой ссылкой (до
  2 раз), затем обложка загружается / ищется заново, а если ничего не помогло - вместо «?» показывается логотип AIMP
- **Проверка обновлений**: используется только `.aimppack` из релиза (если их несколько - с именем плагина).
  AIMP устанавливает его, и как только новый файл плагина на месте, плагин перезапускает AIMP, чтобы он загрузился
  (сам AIMP только предлагает «Перезапустить»). После перезапуска плагин один раз сообщает
  «Discord Rich Presence обновлён до версии ...»

### Изменено
- Настройки, кэш обложек и загрузки хранятся в **папке профиля AIMP**, как того требуют правила для плагинов
  AIMP. Это та же папка, что и раньше (`%APPDATA%\AIMP`, Linux `~/.config/AIMP`), кроме портативного AIMP: там это
  теперь `AIMP\Profile`, а настройки один раз переносятся из старого места
- Русский / украинский: вкладка *О плагине* сообщает, что эти переводы выполнены с помощью ИИ
- Настройки, в которых ещё выбран catbox.moe (прежний вариант по умолчанию), один раз переключаются на x0.at;
  catbox.moe по-прежнему можно выбрать на вкладке *Обложка*

### Исправлено
- 32-битный AIMP: живой предпросмотр (вкладка *Вид*) и фото автора (вкладка *О плагине*) оставались пустыми. AIMP
  передаёт область рисования по ссылке, а C++-заголовок SDK объявлял её по значению
- AIMP 4.70: при закрытии настроек появлялось «Invalid pointer operation» (AIMP 4 сам освобождает страницу
  настроек)
- Windows: «Импорт…» больше не меняет текущую папку AIMP

## 1.5.2

### Исправлено
- Вкладка *Сервис*: «Экспорт…» и «Импорт…» в Windows ничего не делали - окно выбора файла не появлялось. Теперь
  открывается обычное окно Windows «Сохранить как» / «Открыть» (в папке данных плагина, с предложенным именем
  файла)
- Загрузка на catbox.moe («HTTP 200: no answer»): загрузка больше не перенаправляется. Вероятная причина: Windows
  превращает перенаправленную загрузку в пустой запрос, на который catbox ничего не отвечает. Кроме того, запрос теперь соответствует
  примеру catbox (поле `userhash`, заголовок `Accept`). Если загрузка всё же не удалась, журнал показывает статус
  HTTP, отправленный размер и что сообщил сервер (адрес перенаправления, сервер, длина); обложка, как и раньше,
  ищется в интернете

## 1.5.0

### Новое
- **Вкладка «О плагине»**: автор, ссылки на GitHub (версии, сообщить о проблеме) и полный список изменений -
  установленная версия всегда сверху
- **Проверка обновлений**: ищет новую версию на GitHub - при каждом запуске AIMP, раз в день, раз в неделю или раз в
  месяц (или отключена). Новые версии скачиваются, проверяются (SHA-256) и открываются в AIMP, который их
  устанавливает; каждая новая версия открывается автоматически только один раз. Кнопки «Проверить» и
  «Установить» на вкладке «О плагине»
- **Живой предпросмотр** на вкладке *Вид*: показывает, что покажет Discord - карточку активности с обложкой,
  значком воспроизведения / паузы, текстами и полосой прогресса, а также вашу строку в списке участников - прямо
  во время ввода, ещё до нажатия «Применить». Если ничего не играет, показывается пример; если статус скрыт,
  предпросмотр объясняет почему
- **Предпросмотр обложки** на вкладке *Обложка*: текущая обложка и откуда она взята (теги файла, изображение в
  папке, Deezer, iTunes, ...), со ссылкой на изображение
- **Вкладка «Сервис»**: данные соединения (канал, ID приложения, последнее обновление), «Тестовый статус»,
  «Переподключить», последние записи журнала, скрытие статуса для определённых плейлистов, выбор языка, экспорт /
  импорт настроек. Сюда же перенесена опция своего приложения Discord
- **Языки**: плагин следует языку интерфейса AIMP - встроены английский, немецкий, русский и украинский; язык можно
  также выбрать на вкладке *Сервис*. Другие языки можно добавить файлами `Langs\<имя>.lng` без новой сборки
- Новая подстановка `%playlist%` (имя плейлиста, из которого запущен трек)

### Изменено
- Вкладка *Ссылки* теперь часть вкладки *Вид* (6 вкладок: Общие, Вид, Обложка, Источники, Сервис, О плагине)
- `%status%` («Играет» / «Пауза») выводится на языке плагина
- Windows: файл настроек сохраняется в Юникоде (UTF-16) - тексты на любом языке (например, кириллица в своих
  строках или фильтрах) сохраняются правильно. Старые файлы преобразуются автоматически

### Исправлено
- **Linux**: плагин теперь работает практически на любом дистрибутиве последних десяти лет (glibc 2.17 или новее:
  Ubuntu 18.04+, Debian 9+, Mint, Fedora, Arch, ...). Прежним сборкам могла требоваться очень новая glibc (до 2.38,
  например Ubuntu 24.04), и тогда они не загружались
- Linux: плагин больше не экспортирует в AIMP свою встроенную библиотеку C++ (только точку входа)
- Выход из AIMP мог занимать несколько секунд, пока обложка искалась в интернете - теперь текущие загрузки сразу
  прерываются

### Внутри
- Размер файла меньше половины от 1.4.1 (Windows x64: 0,5 МБ вместо 1,3 МБ, Linux: 0,55 МБ вместо 1,8 МБ) и реже
  пробуждения процессора: оптимизация по размеру, без библиотек iostreams / filesystem, фоновые потоки
  просыпаются только когда есть работа
- Единое чтение / запись настроек для Windows и Linux; ручные правки INI-файла подхватываются во время работы AIMP
  на обеих системах
- Тесты теперь также проверяют проверку обновлений (поддельный сервер GitHub), предпросмотры (отрисованные в
  изображения), смену языка, экспорт / импорт, тестовый статус, переподключение и фильтр плейлистов - на Linux и
  на обеих сборках Windows под Wine

## 1.4.1

### Исправлено

  видны вовсе (поля ввода и выпадающие списки). Элементы не были привязаны, поэтому AIMP сдвигал их, когда вкладка
  получала окончательный размер. Теперь все элементы привязаны к левому верхнему углу и сохраняют своё положение

### Изменено
- README: новые снимки всех вкладок настроек (в стиле интерфейса AIMP)

### Внутри
- Тесты теперь проверяют, что каждый элемент страницы настроек привязан и имеет правильный размер, чтобы эта
  ошибка разметки не вернулась незамеченной

## 1.4.0

### Новое
- **Вкладка настроек на Linux**: страница настроек теперь строится через UI-API AIMP (`IAIMPServiceUI`) вместо
  элементов Windows. Нативный AIMP для Linux получает ту же страницу *Настройки -> Плагины -> Discord Rich
  Presence*, что и Windows (Общие / Вид / Обложка / Онлайн-источники / Ссылки). Спасибо DarkDrawKill с форума AIMP
  за идею
- **Следует скину AIMP**: элементы рисует сам AIMP, поэтому страница соответствует текущему скину (в том
  числе тёмному)
- **Один пакет для всех платформ**: `aimp_discord_rpc.aimppack` содержит Windows 32 бит, Windows 64 бит и Linux;
  AIMP выбирает подходящую сборку

### Изменено
- «Developer Portal», «Создать» (Spotify) и «Получить токен» (Discogs) теперь ссылки, которые AIMP открывает в
  браузере (работает и на Linux)
- «Очистить кэш обложек» показывает подтверждение на странице, а не в окне сообщения
- INI-файл на Linux по-прежнему можно править вручную во время работы AIMP

### Исправлено
- Настройки, сохранённые во время (пере)подключения плагина к Discord, применялись только при смене трека

### Внутри
- Не осталось кода интерфейса Win32 (нет зависимостей от comctl32 / uxtheme / shell32)
- `tools/make_aimppack.py` собирает пакет; CI собирает и тестирует все платформы и прикладывает `.aimppack`
- Тесты управляют страницей настроек через имитацию UI-сервиса AIMP (открыть, изменить, Применить, сохранить,
  статус использует новое значение) на Linux и на обеих сборках Windows под Wine

## 1.3.0 (по сравнению с 1.1.0)

### Новые платформы
- **Windows 32 бит**: новая сборка x86 для 32-битного AIMP (точка входа плагина теперь правильно экспортируется и
  для 32 бит, поэтому AIMP может его загрузить)
- **Linux (нативно)**: новый `aimp_discord_rpc.so` для AIMP для Linux (x86_64)
  - общается с Discord через его Unix-сокет; нативный Discord, Flatpak, Snap и Vesktop находятся автоматически
  - настройки в `~/.config/AIMP/DiscordRPC.ini`, создаются при первом запуске со всеми опциями; изменения файла
    применяются во время работы AIMP
  - онлайн-обложки используют системный libcurl (загружается во время работы - без него плагин всё равно
    работает, только без онлайн-обложек)
- **Wine**: DLL для Windows распознают запуск AIMP под Wine и подключаются напрямую к Discord для Linux - никакая
  программа-мост не нужна

### Новые возможности
- **Кликабельное название трека**: клик по названию в Discord открывает поиск на YouTube по исполнителю и
  названию (новая вкладка *Ссылки*; вместо него можно использовать свою ссылку с подстановками)
- **Работает без своего приложения Discord**: поле Application ID перенесено в *Общие -> Дополнительно:
  использовать своё приложение Discord*. По умолчанию используется встроенное приложение
- **Дружит с PreMiD**: во время паузы статус по умолчанию скрывается, чтобы показывались другие активности
  (например, PreMiD). Вариант «Показывать статус паузы» по-прежнему доступен

### Изменено
- Вторая строка по умолчанию теперь `by %artist%` (было `%artist%`)
- Опция паузы «Очистить статус» переименована в «Скрывать (видна PreMiD и др.)»
- Удалена вкладка *Кнопки* (Discord никогда не показывал кнопки в вашем собственном профиле) - вместо неё
  кликабельное название
- Удалены поля ключей ресурсов (значки воспроизведения / паузы / запасной); используются значки встроенного
  приложения
- Настройки из 1.1.0 переносятся автоматически: свой Application ID сохраняется, и опция «использовать своё
  приложение Discord» включается. Поведение при паузе при обновлении один раз устанавливается в «Скрывать» (можно
  вернуть на вкладке *Общие*)
