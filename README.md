Goal for 1.5: 
Automatic updates: the plugin checks for new versions itself and installs them through AIMP - no more manual downloads
Live preview: a preview right in the settings that shows exactly how your Rich Presence will look in Discord - while you change the texts, before you press "Apply"
Built-in changelog: see what is new directly in the plugin, with the installed version on top
Languages: the plugin detects AIMP's language automatically, and you can also choose the language yourself in the settings
